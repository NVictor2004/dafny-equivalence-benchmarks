## Overview
This repository contains a dataset of equivalent Dafny functions. These are designed to be used to benchmark program equivalence checkers. Each file contains at least one pair of equivalent Dafny functions and a proof proving each pair's equivalence. 

## Source
The vast majority of these examples have been taken from the program equivalence tests for the Stainless program verifier (https://github.com/epfl-lara/stainless/tree/main/frontends/benchmarks/equivalence) and converted from Scala into Dafny. The remaining tests have been written by hand.
